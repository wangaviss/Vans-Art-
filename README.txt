VAS ART — Website Souvenir Wedding

Cara menggunakan:
1. Ekstrak file ZIP.
2. Buka folder vasart-wedding lalu buka index.html di browser.
3. Untuk mengubah nomor WhatsApp, buka index.html dan cari:
   const phone="6281234567890";
   Ganti dengan nomor WhatsApp bisnis Anda (format kode negara, tanpa + atau spasi).
4. Ubah harga, nama produk, deskripsi, dan gambar pada array `items` di bagian script.
5. Foto produk demo menggunakan URL Unsplash, sehingga memerlukan koneksi internet. Ganti dengan foto produk milik Anda untuk versi produksi.

Catatan:
- Harga dan minimum order adalah contoh/demo, sesuaikan sebelum website dipublikasikan.
- Testimoni adalah contoh teks, ganti dengan testimoni pelanggan asli.
- Form newsletter saat ini berupa demo dan belum tersambung ke layanan email.
- Website dibuat dengan HTML, CSS, dan JavaScript murni; tidak membutuhkan instalasi framework.
